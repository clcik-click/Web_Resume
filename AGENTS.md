# AGENTS.md

## Scope
Repository root guidance for all work under this project.

## Rules
- Do not edit `node_modules` or generated build output in `web-resume/dist`.
- Treat `web-resume` as the app root for code changes.
- Prefer minimal, targeted changes over broad rewrites.

## Validation
- Run checks from `web-resume`:
  - `npm run lint`
  - `npm run build`
